# Changelog

Формат по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Записи для 4.1.2 и 4.2.0 восстановлены по коду: в репозитории не было истории изменений.

## [Не выпущено] — 4.6.0
### Добавлено
- **«Главная» — новый первый экран.** Карточка iPhone: имя, модель, iOS, кабель или Wi-Fi, сколько приложений на телефоне (после сравнения), свободное место. «Установить IPA с диска…» и перетаскивание .ipa на «Главную» сразу ставят файл на iPhone. Три плитки «Нет на iPhone / На iPhone / Обновить» открывают нужную вкладку «Покупок» (если сравнения ещё не было, запускают его). Текущая загрузка с прогрессом и отменой, «Недавно» — последние загрузки и установки.
- Первый запуск: три шага с галочками — компоненты → Apple ID → iPhone. Нет телефона: подсказка «Подключите кабелем или по Wi-Fi» и «Искать снова».
- Ядро: свободное и общее место на устройстве при поиске (`ideviceinfo -q com.apple.disk_usage`, поля `DiskTotal`/`DiskFree`).
- **«Удалить с iPhone»** в «Покупках» (кнопка и меню появляются, когда выбраны приложения, которые стоят на телефоне): с подтверждением, по одному, с итогом и записью в историю (`ideviceinstaller uninstall`).
- «Поиск»: кнопка **«На iPhone»** рядом со скачиванием (раньше «Скачать и установить» было только в меню по правому клику).
- Модель устройства по-человечески: `iPhone16,2` → «iPhone 15 Pro Max» (iPhone 8 … 17; неизвестное — как есть).

### Исправлено
- Повторное «Скачать» в «Поиске» для уже скачанной версии создавало копии `_2`, `_3`… Теперь программа спрашивает: поставить на iPhone, скачать заново или отмена.

### Изменено (ещё)
- «Поиск» открывается на вкладке «Популярные»; кнопка «Скачать последнюю» → «Скачать на ПК».
- «Диагностика» → «О программе»: без упоминания IPA Downloader (уведомление в `LICENSE` и `THIRD_PARTY_NOTICES.md` остаётся).

### Изменено
- Меню: подписи и иконки крупнее; «Устройства» переехали на «Главную» (полный экран — кнопка «Все устройства»), «Apple ID» — по клику на аккаунт внизу (буква-аватарка с точкой-статусом); внизу кнопка «☕ На кофе» (настройка `TipJarUrl`).
- `Ctrl+1…5` — разделы меню по порядку: Главная, Покупки, Поиск, Загрузки, Файлы IPA.

## [4.5.1] — 2026-11-09
### Исправлено
- **Вход в Apple ID снова работает.** ipatool обновляется напрямую из релизов [ipatool-cpp](https://github.com/Sorvigolova/ipatool) (`ToolRepo`, архив `<платформа>_ipatool-cpp.zip`), без ожидания новой сборки IPA Downloader. Версия 1.3.0 поддерживает новый вход Apple (ноябрь 2026). Версия ipatool-cpp записывается в `MainApp/ipatool-cpp-version.txt`; если её нет (ipatool из набора IPA Downloader), обновление предлагается один раз. Первая установка по-прежнему берёт набор IPA Downloader (инструменты iPhone) и сразу доставляет свежий ipatool-cpp.
- **Ложные срабатывания антивируса на `IPA_PILOTDREDD.exe`.** Запускатор больше не запускает скрытый `powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden`: скрипт выполняется встроенным Windows PowerShell внутри exe. Exe не пересобирается от версии к версии (хранится в `tools/Launcher` с хешем исходников), чтобы у файла копилась репутация.
- **Сбои GitHub (502/503/504, таймаут) при загрузке компонентов и проверке обновлений:** до 3 автоматических повторов, затем понятное сообщение «GitHub временно не отвечает…» вместо «Исключение при вызове "GetResponse"…».

### Добавлено
- GitHub Actions: тесты и самопроверка GUI (в том числе через `IPA_PILOTDREDD.exe`) при каждом push; релиз по тегу собирается на серверах GitHub с подписью происхождения архива (`gh attestation verify`).
- `tools/Make-Screenshots.ps1`: кадры «Нет на iPhone», «Обновить на iPhone» и устройство по Wi-Fi.

## [4.5.0] — 2026-11-07
### Добавлено
- **«Сравнить с iPhone»** в «Покупках»: список приложений на подключённом iPhone/iPad (`ideviceinstaller list --user`) сопоставляется с историей покупок. Новые вкладки «Нет на iPhone», «На iPhone», «Обновить на iPhone» и колонка «На iPhone» (версия на устройстве). Из «Нет на iPhone» можно выделить всё и нажать «Скачать и установить». Сопоставление: App Store ID из `iTunesMetadata` устройства, иначе bundle id (из App Store Lookup или из скачанного IPA). Если сопоставить нельзя — «Не сопоставлено», а не «Нет». Разбор вывода: XML с App Store ID → XML → текст (оба формата ideviceinstaller); нераспознанный вывод — понятная ошибка и начало ответа в журнале.
- **Wi-Fi:** «Устройства» ищут iPhone/iPad и по кабелю, и по сети (`idevice_id -n`, `ideviceinfo -n`), колонка «Подключение». Установка и сравнение работают по Wi-Fi. Подсказка, как включить синхронизацию по Wi-Fi. Если заблокированный iPhone по Wi-Fi не отвечает («Could not connect to lockdownd: Mux error»), установка повторяется до 3 раз (без лишнего `upgrade`), а итоговая ошибка — «iPhone не отвечает по Wi-Fi…» (`Err.WifiUnreachable`), а не «нет доверия».
- **Совместимость с iOS** в «Покупках»: «Нужна iOS N», если приложение не пойдёт на подключённом устройстве (минимальная iOS из App Store).
- **Новая версия программы:** проверка при запуске (и кнопкой в «Диагностике») смотрит релизы IPA PILOTDREDD на GitHub (`AppRepo`) и показывает «Вышла IPA PILOTDREDD X» с кратким списком изменений и ссылкой на релиз. Файлы программы сами не заменяются.
- Ошибки входа после изменений Apple в ноябре 2026 (`status=301/204/403/404/500/503`, `redirect with no location header`, kda2495/IPA_Downloader#29) показываются как «Apple изменила способ входа…» с советом не выходить из сохранённых аккаунтов, а не как непонятная ошибка.
- Проверка свободного места перед загрузкой (размер из App Store × 1,5 + 200 МБ; без размера — 300 МБ): `Err.NoSpace` до запуска ipatool; нехватка места не помечает приложение «Не удалось скачать».

### Изменено
- Иконки в «Покупках» загружаются параллельно (до 6 одновременно).
- Фоновых задач одновременно — до 8 (было 4): загрузка не ждёт, пока догрузятся иконки.
- Ссылка в «Диагностике» → «О программе» ведёт на репозиторий IPA PILOTDREDD.

## [4.4.0] — 2026-11-03
Аудит и план: [docs/AUDIT_4.4.md](docs/AUDIT_4.4.md). Версия программы одна — файл `VERSION`.

### Добавлено

- Статусы: «Можно скачать», «Скачано», «Есть версия N», «Нет в App Store» (с пояснением, что купленное часто всё равно отдаётся), «Не удалось скачать» (только после реальной попытки, с текстом Apple), «Не проверено». Статуса «Не приобретено» нет.
- Вкладки-фильтры со счётчиками, поиск (название, разработчик, bundle id, ID), сортировка по колонкам, массовое скачивание, прогресс в строке, «Повторить неудачные», контекстное меню (версия, папка, App Store, копировать ID), горячие клавиши (Ctrl+F, F5, Enter, Ctrl+C, Ctrl+L, Ctrl+1…5).
- Кэш библиотеки покупок по аккаунту `Files/Purchases/<хеш email>.json` (email в имени файла не хранится), ошибки попыток загрузки переживают пересканирование.
- В поиске статус «В покупках» / «Нет в истории покупок» (только если история этого аккаунта получена).

### Изменено
- Новая визуальная система: нейтральная палитра, радиусы 4/6, компактные контролы, вкладки вместо «пилюль», выделение раздела полосой, журнал свёрнут в строку состояния.
- Навигация: Покупки · Поиск · Загрузки · Файлы IPA · Устройства · Apple ID · Настройки · Диагностика. «Главная» удалена; «Покупки аккаунта» и «Получено скриптом» убраны из поиска.
- История в «Загрузках» показывает все операции (загрузка, лицензия, установка).
- Купленные приложения скачиваются без `--purchase`.
- «Проверить обновления» показывает последний релиз upstream без сравнения несвязанных номеров версий.
- `ipatool-cpp` в `MainApp` (все 4 платформы) обновлён из релиза IPA Downloader 4.3.3 (SHA-256 архива сверен): исправлены SSL через прокси и вход при включённом CFG. Инструменты устройств не менялись. Прежние бинарники — в `MainApp_previous/`.

- Название продукта — **IPA PILOTDREDD** (окно, боковая панель, «О программе», журнал, отчёт). Имена файлов и папок не менялись.
- Вкладка «Нет в App Store» показывает все снятые с продажи приложения, включая уже скачанные («Скачано · нет в App Store»).
- «Поиск»: иконки и версии для популярных/своего списка (iTunes Lookup, общий кэш иконок), второстепенные действия перенесены в контекстное меню.
- «Загрузки»: «Удалить из истории» (Delete) и «Очистить историю» (с подтверждением; файлы IPA не трогаются).
- Шрифт интерфейса Segoe UI Variable 14 (запасной Segoe UI), иконки Segoe Fluent Icons; Consolas убран из таблиц.
- «Поддержать PILOTDREDD» неактивна, включится при `TipJarUrl=https://…` в `Settings.txt`.
- Очередь загрузок сохраняется в `Files/Queue.json` (по аккаунту, без email) и после перезапуска предлагается продолжить; начатая загрузка начинается заново.
- «Скачать и установить» / «Установить на iPhone» в «Покупках» (кнопка и меню) и в «Поиске» (меню): поиск iPhone при необходимости, выбор устройства, проверка iOS и подписи, установка по очереди; статусы «Ждёт установки», «Установка…», «Установлено», «Ошибка установки» (повтор — «Повторить»).
- `tools/Run-GuiSelfTest.ps1` — самопроверка GUI в копии приложения; сценарий покрывает установку на фейковое устройство (`tests/fixtures/fake-idevice*.cmd`).
- `IPA_PILOTDREDD.exe` — запускатор с иконкой без консольного окна (`tools/Build-Launcher.ps1`, csc из .NET Framework; исходник `tools/Launcher/Launcher.cs`). Иконка `src/GUI/Assets/app.ico` — у окна, диалогов и exe.
- `tools/Build-Release.ps1` собирает `IPA_PILOTDREDD_<версия>_portable.zip` из своего `MainApp` (с exe и версией ipatool), проверяет отсутствие личных данных, печатает SHA-256.
- Одна версия программы — файл `VERSION` (окно, exe, архив); номера версий upstream убраны из уведомлений.
- Публичный релиз без бинарников: при первом запуске «Загрузить компоненты» ставит ipatool и инструменты устройств из официального релиза IPA Downloader (SHA-256). `Build-Release.ps1 -IncludeBinaries` — сборка для себя.
- Подготовка к GitHub: белый список в `.gitignore`, `LICENSE` (MIT + уведомление IPA Downloader), `THIRD_PARTY_NOTICES.md`, README со скриншотами (`tools/Make-Screenshots.ps1`, демо-данные), документация в `docs/`.
- Проверка при запуске (`CheckUpdatesOnStartup`, по умолчанию вкл.): тихий запрос к GitHub, итог — уведомление «Всё готово к работе» (версия ipatool, Apple ID, инструменты устройств) или «Доступно обновление ipatool». Обновление по кнопке: загрузка с прогрессом, проверка SHA-256, пробный запуск, резервная копия в `MainApp_previous`, откат при сбое. Версия встроенного ipatool — `MainApp/ipatool-version.txt`.

### Исправлено
- Прогресс загрузки: ipatool-cpp печатает `PROGRESS:N`, разбор понимал только `N%` — процентов не было.
- Журнал: каждая строка прогресса писалась в файл (≈11 000 строк за загрузку).
- DSID аккаунта попадал в журнал из вывода `kbsync` — теперь вывод `kbsync` не пишется, `dsid=` маскируется.
- Запись файлов через `File.Replace` (атомарно на NTFS) вместо копирования с удалением.
- Дубли и подписки/встроенные покупки в истории покупок.

## [4.3.0] — 2026-10-17
Новая GUI-версия **IPA Dredd 4.3** в `IPA_Dredd_4.3.0/` (Windows PowerShell 5.1 + WPF). Версии 4.1.2 и 4.2.0 не изменялись.

### Добавлено
- Графический интерфейс: Главная (окружение, аккаунт, устройства, библиотека, последние операции, быстрые действия), Каталог, Загрузки, Библиотека, Устройства, Apple ID, Настройки, Диагностика.
- Модуль бизнес-логики `IPADredd.Core`, отделённый от UI (совместим с PowerShell 5.1/7).
- Фоновые операции (runspace-пул) с прогрессом, отменой и журналом. Окно не зависает.
- Вход в Apple ID из GUI (email, пароль, код 2FA) и вход через консоль; маркер `login` для совместимости с 4.2.
- Очередь загрузок, отмена с завершением процесса и очисткой временных файлов, «Повторить», выбор папки загрузок.
- Диалог выбора версии с подгрузкой номеров версий пачками.
- Библиотека: метаданные из XML- и бинарных `Info.plist`, App Store ID и разработчик из `iTunesMetadata.plist`, фильтр, детали, удаление.
- Установка на выбранные устройства с предупреждением о несовместимой iOS и итоговым отчётом.
- История загрузок/лицензий/установок `Files/DownloadHistory.json`.
- Диагностика с подсказками и экспорт отчёта без личных данных; журнал `Logs/` с маскированием секретов и email.
- RU/EN и тёмная/светлая темы с переключением на лету.
- `tools/Build-Release.ps1` (zip без личных данных), `tools/Fix-Encoding.ps1`, 30 автотестов ядра, режимы `-SelfTest` / `-Screenshot` / `-TestIpatool`.

- Установка любого IPA с диска: «Выбрать IPA с диска…» на экране устройств или перетаскивание файла в окно (без копирования), «Добавить IPA…» в библиотеке (копия в папку библиотеки). Внешние файлы из списка только убираются, с диска не удаляются.
- Проверка подписи IPA: тип (App Store, Ad Hoc, Development, Enterprise, Distribution, без подписи, расшифрованный — по `cryptid` в Mach-O), срок профиля, наличие UDID устройства в профиле. Перед установкой — предупреждение о проблемных парах «IPA → устройство».
- Ответ App Store «item is temporarily unavailable» распознаётся отдельно, с подсказкой.

### Изменено (по сравнению с 4.2)
- Имя файла IPA без Apple ID, совпадения не перезаписываются (`_2`). Добавление аккаунта в имя — настройка.
- Загрузка идёт во временную папку через `-o`, корень программы не трогается.
- `--purchase` включается флажком «Получать бесплатную лицензию» (по умолчанию включён, как в 4.2).
- Списки обновляются в фоне, старт не блокируется. Проверка обновлений — по кнопке.
- «Выйти» удаляет только активную сессию; настройки, другие аккаунты и `keychain-passphrase` остаются.

### Исправлено (по сравнению с 4.2 и прототипом)
- Бинарные `Info.plist` больше не превращаются в `App`/`0`/`NA` (A1).
- Покупка записывается в `PurchasedAppsList.json` только при успехе (A6).
- Отсутствие DLL libimobiledevice не останавливает программу (A9).
- Прототип: вход из GUI теперь создаёт маркер (G2), passphrase сохраняется до использования (G3) и не показывается в окне консоли (G4), поиск без масок (G6).

- Установка на устройство падала до запуска с ошибкой «Типы аргумента не совпадают» (Devices.ps1:115): в Windows PowerShell 5.1 `@()` над `List[object]` бросает исключение. Найдено на реальном iPhone.

### Документация
- `docs/`: аудит, архитектура, спецификация GUI, ADR, функции, планы, чек-листы, безопасность, руководство разработчика.
