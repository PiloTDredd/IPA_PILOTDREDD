Вход в Apple ID снова работает, меньше ложных срабатываний антивируса.

### Исправлено
- **Вход в Apple ID.** Apple 6 ноября изменила способ входа, и новый вход перестал работать во всех похожих программах. Программа теперь берёт ipatool напрямую у его автора ([ipatool-cpp 1.3.0](https://github.com/Sorvigolova/ipatool/releases/tag/1.3.0)) — после обновления при запуске появится «Доступно обновление ipatool» → «Обновить» (файл проверяется по контрольной сумме, старая версия сохраняется в `MainApp_previous`). Дальше исправления ipatool будут приходить без ожидания новой версии IPA PILOTDREDD.
- **Антивирус блокировал `IPA_PILOTDREDD.exe`** («файл содержит вирус или потенциально нежелательную программу»). Это было ложное срабатывание на способ запуска: exe запускал скрытый PowerShell. Теперь PowerShell работает внутри самого exe, а файл не меняется от версии к версии.
- **Ошибка «502 Недопустимый шлюз» при загрузке компонентов.** Это временный сбой GitHub: программа сама повторяет попытку до 3 раз, а если GitHub так и не ответил — пишет об этом понятно.

### Прозрачность
Релиз собран на серверах GitHub из кода этого репозитория. Проверить, что архив не подменён:
```
gh attestation verify IPA_PILOTDREDD_4.5.1_portable.zip -R PiloTDredd/IPA_PILOTDREDD
```

### Как обновиться
Скачайте `IPA_PILOTDREDD_4.5.1_portable.zip`, откройте его и **скопируйте содержимое папки `IPA_PILOTDREDD_4.5.1` поверх своей папки с программой** (с заменой файлов). Скачанные IPA, настройки, история, аккаунты и компоненты сохранятся. После запуска нажмите «Обновить» в уведомлении про ipatool. Уже сохранённые аккаунты продолжат работать — выходить из них не нужно.
