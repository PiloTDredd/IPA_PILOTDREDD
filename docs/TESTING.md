# Тестирование

## 1. Автоматические проверки
```powershell
cd <папка программы>
powershell -NoProfile -ExecutionPolicy Bypass -File tests\Run-Tests.ps1      # тесты ядра
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Run-GuiSelfTest.ps1   # все экраны, темы, языки + сценарий (в копии программы)
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Run-GuiSelfTest.ps1 -ViaLauncher   # то же через IPA_PILOTDREDD.exe
powershell -NoProfile -ExecutionPolicy Bypass -File tools\Make-Screenshots.ps1  # скриншоты README на демо-данных
powershell -NoProfile -ExecutionPolicy Bypass -File IPA_Dredd.ps1 -Screenshot .\screens  # PNG каждого экрана
```

Что покрывают тесты ядра:
- синтаксис всех `.ps1` (парсер PowerShell), загрузка модуля;
- маскирование журналов (email, пароль, passphrase, код 2FA, cookie);
- чтение/запись `Settings.txt`, разбор `AppsList.txt`, дедупликация, поиск (включая спецсимволы `[ ] * ?`);
- `PurchasedAppsList.json`: чтение формата 4.1 (объект) и 4.2 (массив), запись всегда массивом;
- разбор plist: XML и бинарный; метаданные IPA из тестового zip;
- имена файлов: шаблон, недопустимые символы, уникализация `_2`;
- сравнение версий iOS;
- запуск процессов: вывод, код возврата, таймаут, отмена;
- поиск бинарников по кандидатам;
- загрузка через фейковый ipatool: перенос, переименование, история, отмена с очисткой temp;
- аккаунты: «парковка» и восстановление файлов в изолированном HOME;
- ключи локализации RU = EN, все `x:Uid` из XAML есть в JSON;
- диагностический отчёт не содержит email и имени пользователя Windows.

### 1.1 Сценарий GUI на фейковом ipatool
Проверяет настоящий TaskRunner (runspace, очередь, колбэки) без сети. Запускать в **копии** папки приложения, чтобы не трогать свои `Files/` и `Apps/`:
```powershell
# проще: tools\Run-GuiSelfTest.ps1 (делает копию сам). Вручную — в копии папки программы; FAKE_STATE_DIR — пустая папка с файлом logged_in
$env:FAKE_STATE_DIR = 'C:\Temp\fake_state'
powershell -NoProfile -ExecutionPolicy Bypass -STA -File IPA_Dredd.ps1 -SelfTest -TestIpatool tests\fixtures\fake-ipatool.cmd
```
Шаги: проверка аккаунта → поиск в App Store → загрузка из каталога → обновление библиотеки → статус «В библиотеке» → фильтр библиотеки (не влияет на экран устройств) → отмена медленной загрузки → «Последние операции» на главной.
