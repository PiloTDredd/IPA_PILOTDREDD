# Безопасность: Apple ID, секреты, логи, локальные данные

## 1. Что считается секретом
| Данные | Где | Правило |
|---|---|---|
| Пароль Apple ID | только в памяти на время входа | никогда не сохраняется, не логируется, не попадает в отчёты |
| Код 2FA | в памяти | так же, как пароль |
| Сессия ipatool (`account`, `cookies`) | `~/.ipatool/`, `~/.ipatool/<email>/` | не копировать в репозиторий, архивы и отчёты; не читать содержимое в коде 4.3 (только перемещать файлы) |
| Keychain passphrase | `~/.ipatool/keychain-passphrase` (DPAPI, привязан к пользователю Windows) | расшифровывается только в момент вызова ipatool; в журнале `***` |

## 2. Личные данные (не секреты, но не для публикации)
- **Email Apple ID**: ключи в `PurchasedAppsList.json`, имена папок в `~/.ipatool`, имена файлов IPA из 4.1/4.2. В журналах 4.3 маскируется (`m***@mail.ru`), в диагностический отчёт не попадает.
- **Имя владельца аккаунта** (из `auth info`): показывается только в окне, в журнал не пишется.
- **IPA-файлы**: внутри `iTunesMetadata.plist` есть Apple ID покупателя. 4.3 это поле не читает. Не публикуйте IPA.

## 3. Правила для репозитория
- В git попадает только белый список из `.gitignore` (код, тесты, документация, `Files/AppsList.txt`). Всё остальное — `Apps/`, `Logs/`, `Files/*` с историями, очередью (`Queue.json`) и кэшем покупок (`Purchases/`, `Cache/`), `Settings.txt`, `MainApp*/`, `dist/` — игнорируется по умолчанию.
- В документации, тестах и примерах используются только вымышленные адреса вида `user@example.com`.
- `tools/Build-Release.ps1` собирает zip из белого списка и останавливается, если находит IPA, журналы, истории, очередь, кэш покупок или файлы сессии. Бинарники (ipatool-cpp со встроенными библиотеками Apple, GPL-инструменты устройств) в релиз не входят: программа скачивает их при первом запуске из официального релиза IPA Downloader с проверкой SHA-256.


## 4. Известные ограничения ipatool-cpp
1. **Пароль при входе из GUI передаётся аргументом** `-p` (без терминала ipatool не принимает пароль иначе, это проверено). Пока идёт вызов (секунды), командную строку процесса могут увидеть процессы того же пользователя и администраторы. Снижение риска: вызов короткий, в журнал пишется маска. На общем компьютере используйте «Войти через консоль»: там пароль вводится скрыто.
2. **Keychain passphrase передаётся аргументом** при каждом вызове (если шифрование включено). Это тот же класс риска.
3. **Режим отладки** (`--debug`) печатает запросы и ответы, включая заголовки. 4.3 маскирует известные шаблоны, но включайте отладку только для разбора проблемы и не публикуйте журналы отладки.
4. На macOS/Linux консоль 4.2 использует пустую passphrase: сессия хранится без дополнительного шифрования, полагаясь на права доступа к домашней папке.

## 5. Маскирование в 4.3 (`Protect-LogText`)
- `[\w.+-]+@[\w-]+(\.[\w-]+)+` → первая буква + `***@домен`.
- Значения после `-p`, `--password`, `-a`, `--auth-code`, `--keychain-passphrase` → `***`.
- Заголовки `Cookie:`, `Set-Cookie:`, `X-Dsid`, `Authorization:`, `password=` / `token=` в выводе ipatool → значение `***`.
- Маскирование выполняется **до** записи в окно и файл.
- Вывод `auth info` и `auth login` в журнал не пишется вообще (там имя владельца аккаунта), только замаскированная команда и код возврата (ADR-015).
- Покрыто тестами в `tests/Core.Tests.ps1`.

## 6. Диагностический отчёт
Содержит: версии ОС, PowerShell, .NET, 4.3; найдены ли бинарники и их размеры; права на запись в папки; число IPA; наличие (да/нет) сессии и маркера; настройки без URL с токенами.
Не содержит: email, имя, пути с именем пользователя (заменяются на `~`), содержимое `~/.ipatool`, журналы.

## 7. Удаление данных
- «Выйти» в 4.3 = `auth revoke` + удаление активных файлов сессии. Настройки и другие аккаунты остаются (в отличие от «выйти из всех» в 4.2, A12).
- «Забыть аккаунт» удаляет `~/.ipatool/<email>/` после подтверждения.
- Удаление IPA только по одному файлу с подтверждением. Массового удаления папки, как в 4.2, в GUI нет.

## 8. Сеть
Программа обращается только к: серверам Apple (через ipatool), `itunes.apple.com/lookup` и `*.mzstatic.com` (метаданные и иконки купленных приложений, без авторизации), `api.github.com` и `github.com` (проверка и загрузка компонентов из релизов IPA Downloader), `raw.githubusercontent.com` (список популярных приложений). Телеметрии нет. Чаевые — только по нажатию кнопки (открывается браузер).
